# Department of Agricultural Engineering - Image Gallery

A simple Flask web app for uploading and viewing department-related images.

## Setup

1. Install Flask:
   pip install flask

2. Run the app:
   python app.py

3. Open http://127.0.0.1:5000/ in your browser.

## Structure

- app.py - Flask backend
- templates/index.html - gallery page
- templates/upload.html - upload form
- static/style.css - styling
- static/uploads/ - uploaded images are stored here
